\begin{abstract}
Проект исследует связь сложности регрессионной модели с bias, variance и
квадратичной ошибкой. На синтетических данных компоненты оцениваются напрямую
по независимым обучающим выборкам. На Diabetes и California Housing
используются repeated cross-validation и paired bootstrap. Для реальных данных
проверяется точное тождество квадратичной ошибки без подмены неизвестного
смещения расстоянием до эталонной модели.
\end{abstract}

\section{Синтетический эксперимент}

Пусть $Y=f(X)+\varepsilon$, где
$\mathbb E[\varepsilon\mid X]=0$ и
$\mathbb V[\varepsilon\mid X]=\sigma^2$. Для squared loss выполняется

\[
\mathbb E_{D,\varepsilon}\left[(Y-\hat f_D(x))^2\right]
=
\left(\mathbb E_D[\hat f_D(x)]-f(x)\right)^2
+
\mathbb V_D[\hat f_D(x)]
+
\sigma^2.
\]

Используется функция $f(x)=\sin(2x)+0.2x^2$ на $X\sim U[-3,3]$ и
$\sigma=0.35$. Для каждой конфигурации строятся 50 независимых обучающих
выборок по 160 объектов. Все модели получают одни и те же выборки и общую
сетку из 240 точек, которая не передается в \texttt{fit}. Случайность данных,
модели и тестового шума задается разными seed sequences. Variance Random
Forest и MLP включает изменение данных и случайность алгоритма.

На конечном числе повторов наивная оценка squared bias содержит Monte Carlo
добавку. Для $m$ повторов используется поправка

\[
\widehat{Bias^2}_{\mathrm{corr}}
=
\frac{1}{n}\sum_i\left(\bar f(x_i)-f(x_i)\right)^2
-
\frac{\widehat{Variance}}{m}.
\]

Variance оценивается с поправкой Бесселя. Из-за несмещенности исправленный
Bias$^2$ может быть немного отрицательным около нуля. Полосы на графике
получены bootstrap перевыборкой 50 prediction vectors.

\section{Нейронная сеть}

Отдельный эксперимент меняет ширину до 256, число скрытых слоев до трех и
L2 параметр $\alpha$. Для ширины от 128 до 256 expected MSE почти не меняется.
Variance также не растет. Это не подтверждает универсальный тезис о том, что
любое увеличение ширины обязательно ведет к переобучению. На этой одномерной
задаче Adam, L2 и остановка по отсутствию улучшения loss ограничивают
эффективную сложность сети. Переход от двух слоев к трем повышает variance с
0.0109 до 0.0128 и expected MSE с 0.1333 до 0.1352.

\section{Реальные данные}

Diabetes содержит 442 наблюдения и 10 признаков. California Housing содержит
20640 наблюдений. Для практичного полного запуска один раз выбираются 5000
строк по фиксированному seed. Исходный датасет загружается средствами
scikit-learn и остается в локальном cache. Масштабирование Ridge и MLP
находится внутри Pipeline и обучается заново на каждом fold.

Модели сравниваются на одинаковых разбиениях RepeatedKFold с 5 folds и 3
повторами. На Diabetes Ridge показывает RMSE $54.86\pm3.05$. MLP и Gradient
Boosting находятся в пределах наблюдаемого разброса. На California Housing
MLP показывает RMSE $0.570\pm0.019$, Random Forest дает $0.612\pm0.021$.

\section{Сложность на Diabetes}

Для одного train-test split используются общие 30 bootstrap samples. У Ridge
усиление регуляризации снижает variance со 106 до 51, при этом средний
bootstrap MSE остается около 2885. У дерева минимум среднего bootstrap MSE
наблюдается при глубине 2, после чего variance быстро растет. Для KNN variance
падает с ростом числа соседей. У MLP ширина 64 устойчивее ширины 128 при всех
трех значениях $\alpha$. Таким образом, реальная часть исследует не только

\section{Точное bootstrap тождество}

Истинная regression function на реальных данных неизвестна. Поэтому bias и
irreducible noise раздельно не оцениваются. Для фиксированного test set и
prediction matrix проверяется точное тождество

\[
\frac{1}{B}\sum_{b=1}^{B}MSE(y,\hat f_b)
=
MSE(y,\bar f)
+
\frac{1}{n}\sum_i Var_b\left(\hat f_b(x_i)\right).
\]

Первое слагаемое объединяет систематическую ошибку относительно наблюдаемых
targets, test noise и эффект выбранного split. Его нельзя называть Bias$^2$.
Второе слагаемое измеряет нестабильность прогноза при перевыборке. Identity
gap во всех строках находится на уровне машинной точности.

\section{Выводы и ограничения}

Классический bias-variance механизм ясно виден у Decision Tree, KNN и Random
Forest. Для Polynomial Ridge после достаточной степени возникает плато. У MLP
ширина сама по себе не вызывает роста variance на синтетической задаче, но
дополнительная глубина и реальный многомерный набор показывают менее устойчивые
режимы. Поэтому общий вывод формулируется по наблюдаемым траекториям, а не как
универсальное свойство всех пяти семейств.

Оценки зависят от конечного числа Monte Carlo и bootstrap повторов. Полосы
неопределенности отражают перевыборку prediction vectors, а не полный повтор
всего исследования. Время обучения зависит от оборудования. На реальных
данных тождество разделяет ошибку среднего прогноза и нестабильность, но не
разделяет bias и noise без дополнительных предположений о неизвестной
регрессионной функции.
